# UHES - 普适异构进化系统

> ⚠️ **项目性质声明**：本项目是在长对话中逐步构建的**概念架构设计**，非已完成的可运行软件。文档中涉及的"插件""数据库""测试""修复""性能数据"等均为对话过程中模拟的概念推演，用于验证架构设计的合理性，不代表真实工程实现。
>
> 系统缩写"UHES"由用户确认；全称"Universal Heterogeneous Evolution System（普适异构进化系统）"经战略评估后确定。

> 系统之母 · 元系统锻造厂 · 基于Meta-Agent范式的智能体系统生成器

## 项目定位

UHES不是单一预测/问答系统，是**生成强大系统的元系统（系统生成器）**。由「系统生成器 + 理论融合器 + 架构进化器」三部分构成，通过理论范式杂交产出可落地业务系统，实现"系统生成系统"递归闭环。

> 以上定位为对话中逐步形成的核心构想，用户未提出异议。

## 核心构件

| 模块 | 说明 |
|------|------|
| **42位专家圆桌** | 跨学科虚拟专家会诊，多视角评审范式融合与系统蓝图 |
| **方法论管家** | 元方法工具箱调度，常驻30条核心方法+120+完整方法论库 |
| **全网络同构扫描** | 学科间结构同构、动力学等价关系挖掘 |
| **交叉验证引擎** | 多系统并行求解，输出结论置信度 |
| **递归自优化** | 系统自我审计、自我修复、进化记忆沉淀 |
| **沙箱快照机制** | 适配临时动态沙箱环境，支持跨会话状态迁移 |
| **系统矩阵** | 全部生成系统统一登记，维护范式标签与依赖关系 |

## 设计硬约束

1. **严格非侵入式扩展架构**：绝不改写主智能体system-prompt；插件以侧车动态加载方式运行；原始代码库保持不变；模块即插即用。
2. **独立存储隔离**：各个插件独立存储、独立数据库，禁止共享同一个连接池，规避锁表风险。
3. **内存上限**：总RAM占用不超过60%；内存可控。
4. **零未来信息、渐进式进化**。
5. **远期高级能力标记为扩展能力，默认关闭**，需要用户显式启用才执行，防止系统无限膨胀冗杂。
6. **修辞约束**：禁止神学、灵魂、造物主、生物免疫类隐喻；全部使用控制论、工程、数学、系统科学术语。

## 运行环境说明

整套UHES运行在**动态分配临时沙箱**环境，无自动持久化。会话中断、新建窗口、长时间闲置均会回收资源。

应对方案：所有核心知识、架构规则依靠**记忆匣提示词**文本快照跨会话迁移；一切内存实时统计数据仅作单次会话参考，不成为系统运行的核心依赖。
