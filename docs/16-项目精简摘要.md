# 16. UHES 项目精简摘要（快速预览）

> 一页式速览:面向快速理解全貌的读者。完整细节见各 docs/XX 与 src/。

## 一句话定位

UHES(普适异构进化系统)是一个**概念级"系统之母"**——把跨学科范式按机制同构杂交,
生成带验证报告的系统蓝图;首个落地 Agent 是「范式演化设计师」。

## 核心机制(一条链路)

```
需求DNA解析 → 范式匹配 → (圆桌) → 方法论推荐 → 杂交决策 → 系统蓝图
→ 验证(8维评分) → 交叉验证 → 验收映射 → 矩阵登记(递归闭环)
   S1        S2      S2.5       S3          S4          S5
                                    S6          S7          S8
```

- **需求DNA**:目标/约束(硬软,8维度)/边界(三桶)/风险/歧义/假设/范式线索
- **范式匹配**:四步加权(领域标签→核心公理→方法论协同→杂交决策)
- **杂交三分支**:单范式 / 结构同构(默认) / 动力学等价(需显式开启)
- **方法论权重三信号**:风险强制 > 范式偏好 > 历史频次
- **保护机制**:每步门控、回退≤1次、降级+回退≥3触发最短路径、递归深度硬上限
