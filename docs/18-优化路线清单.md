# 18. UHES 优化路线清单（LLM 驱动化升级路线）

> 文档性质声明:本文档是 UHES 概念原型**后续优化路线**的正式清单,基于顶尖工程师视角的
> 架构评估(docs/15 冻结审计 + 本清单)。升级方向:概念骨架 → LLM 驱动真实引擎。
> 每项含:目标 / 现状 / 升级动作 / 验收标准。按优先级编号,可从任意项开始执行。

## 0. 总原则

- 冻结保护:升级前必须**显式解冻**对应模块;冻结约束允许"勘误+侧车",LLM 驱动化需
  用户确认解冻后才动引擎核心。
- 每步验证:每项完成后跑通对应场景,回归不破坏既有 phase1~4 与三案例。
- 每步推送:每项提交独立 commit,推送远程,保证本地=沙箱同步。

## 清单

### 1. 需求 DNA 解析 LLM 化
- 现状:规则拆分(关键词/硬编码分类),非真实语义理解。
- 升级:接入 LLM 结构化输出(JSON Schema 约束),支持多轮澄清;
  保留现有 hard/soft 约束、三桶边界、风险/歧义登记 Schema。
- 验收:输入自然语言需求 → 输出符合 REQUIREMENT_DNA Schema 的 JSON,
  硬软约束/边界/风险字段齐全;澄清循环 ≤1 轮。

### 2. 范式匹配 embedding 化(先做)
- 现状:Jaccard 标签相似度(概念简化)。
- 升级:范式库 29 组向量化,需求 DNA 的 paradigm_hints/goal 做 embedding 检索;
  保留四步加权与三信号方法论权重机制,相似度排序改为向量距离。
- 验收:跨学科需求能检索到机制同构的范式(如"证据传递=噪声信道"类映射),
  而非仅关键词命中;匹配输出含 embedding 相似度分数。

### 3. 杂交决策 LLM 评审 + 确定性校验双通道
- 现状:规则分支(单范式/结构杂交/动力学杂交)。
- 升级:LLM 评审杂交合理性 + 确定性公理自洽校验;保留降级分支
  (评审失败 → 结构杂交 → 单范式)。
- 验收:杂交决策输出含 LLM 评审意见 + 自洽校验结果;失败时正确降级。

### 4. 蓝图生成 LLM 化
- 现状:静态模板(S4 输出固定结构)。
- 升级:LLM 生成系统蓝图(模块/接口/数据流),门控校验必填字段与引用闭环。
- 验收:蓝图含模块划分/接口/数据流,门控拦截缺字段/悬空引用。

### 5. 8 维验证 LLM-as-judge 化
- 现状:概念等级(S/A/B/C/D 由规则近似给出)。
- 升级:LLM-as-judge 评估 8 维度 + 确定性指标(字段完整性/引用闭环)混合;
  保留 CONS_01 件间一致性规则。
- 验收:验证报告含 LLM 评分理由 + 确定性检查结果;verdict 可复现。

### 6. 系统矩阵持久化
- 现状:内存 dict(概念)。
- 升级:SQLite 持久化,evolves_from/versions 落地为真实 schema;支持跨运行加载。
- 验收:重启后矩阵可加载;阶段4 递归闭环在真实持久化上可跑。

### 7. 插件运行时真实化
- 现状:函数侧车(动态 import 未实现)。
- 升级:真实插件加载(动态 import + 隔离命名空间 + 资源上限);保留非侵入铁律。
- 验收:插件独立加载/卸载,不污染引擎命名空间;资源超限被拦截。

### 8. 可观测性工程化
- 现状:--trace JSONL(结构化事件流)。
- 升级:OpenTelemetry 全链路 tracing(span 覆盖 S1~S8 + 门控事件);
  指标:各步耗时/降级率/回退率。
- 验收:全链路 tracing 可导出;指标面板可查。

### 9. 测试体系升级
- 现状:概念场景(phase1~4 + 三案例)。
- 升级:LLM mock 层(固定响应) + 真实调用的集成测试矩阵;故障注入保留。
- 验收:测试覆盖 DNA 解析/范式匹配/杂交/验证各环节;回归自动跑。

### 10. 多 Agent 分工
- 现状:单流水线(范式设计师一人)。
- 升级:范式设计师 / 验证器 / 审计器分离,流水线变 Agent 编排。
- 验收:验证器独立评审设计师输出;审计器独立复核交付包。

### 11. API 化
- 现状:CLI 单入口。
- 升级:流水线暴露为 HTTP 服务(提交需求 → 轮询状态 → 取交付包)。
- 验收:HTTP 客户端可完整走一遍流水线。

### 12. 进化闭环真实化
- 现状:阶段4 机制概念落地。
- 升级:矩阵真实版本管理,递归迭代(系统生成系统)真实执行,evolves_from 溯源。
- 验收:真实系统迭代生成新版本,溯源链可查,冗余迭代被阻断。

## 优先级与依赖

- **跳一(1~5)**:概念 → 真实引擎,最大价值跃迁。**✅ 全部完成(2026-10-02)**——S1 LLM解析/S2 embedding匹配/S3 LLM双通道/S4 LLM蓝图/S5 LLM judge,三案例全LLM链路 deliver。
- **跳二(6~9)**:真实引擎 → 工程化(可部署、可信任)。
- **跳三(10~12)**:工程化 → 平台化(多 Agent + 服务化)。
