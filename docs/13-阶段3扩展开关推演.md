## 1. 三项扩展能力设计

### 1.1 动力学等价杂交(phase3_dynamics_hybrid)

| 项 | 结构杂交(阶段1/2默认) | 动力学等价杂交(阶段3扩展) |
|----|----------------------|--------------------------|
| 杂交深度 | `structure`(合并框架层级) | `dynamics`(合并机制/动力学方程层级) |
| 公理自洽检查 | 通过 | **强制**(未通过→降级结构杂交,标记 `dynamics_equivalence_not_verified`) |
| 圆桌评审 | 按触发条件 | **强制**(docs/10 3.5 触发条件第3条) |
| 概念声明 | 不声明 | `dynamics_equivalence_declared` + 等价性说明 |

**概念示例(证据信道编码)**:两范式在"传递-失真-纠错"动力学结构上等价——
信源→噪声信道→纠错恢复 ≡ 原文→翻译抽取链路→冗余锚定恢复。
概念层不编造具体方程系数(遵守"禁神学生物类隐喻、用工程术语"铁律)。

**实现位置**:`src/main.py` S2 侧车 handler + gate(含降级分支)。

### 1.2 系统关系网络(phase3_relation_network)

S8 矩阵登记时建立验证关系:
- `validates`:本系统验证了哪些矩阵内系统(基于范式标签相似度,复用 S6 检索加权)
- `validated_by`:被哪些系统验证
- `relation_network`:边数 + 建立依据说明

**实现位置**:`src/main.py` S8 侧车 handler。

### 1.3 系统自动编排(phase3_auto_orchestration)

概念编排器:给定更大问题,从矩阵中按"领域相关 + 依赖可解"选择系统并编排调用链。
不运行任何真实系统,仅输出编排方案。

**概念示例**:对四语文献做综述并评估证据可信度 →
`sys_lit_review_001`(综述) → `sys_active_inference_001`(证据置信度) →
`sys_narrative_spectrum_001`(文本结构校验)。

**实现位置**:`src/main.py` `_concept_orchestrate()`(概念演示函数)。
