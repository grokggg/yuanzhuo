# 插件架构设计

## 架构总览

UHES采用**调度运行时+插件化侧车架构**，主本体完全不改动，全部功能为可插拔插件。

```
┌─────────────────────────────────────────┐
│              主智能体本体（冻结）          │
│  禁止修改system-prompt / 原生Prompt      │
└───────────────────┬─────────────────────┘
                    │ 侧车动态加载
┌───────────────────▼─────────────────────┐
│         plugin_runtime.py 调度层          │
│  插件注册 / 路由分发 / 链式触发 / 降级保护  │
└───────────────────┬─────────────────────┘
                    │
    ┌───────────────┼───────────────┐
    │               │               │
┌───▼───┐      ┌────▼───┐      ┌────▼───┐
│核心插件│      │业务插件 │      │研究插件 │
│ 12个  │      │ 9个    │      │ 1个    │
└───────┘      └────────┘      └────────┘
```

## 设计硬约束

1. **核心骨架永久冻结**：主本体、调度层核心逻辑不修改
2. **双轨绝对隔离运行**：主本体与插件侧车完全隔离
3. **零共享资源**：独立DB/连接池，禁止共享
4. **内存硬锁60%上限**：总RAM占用不超过60%
5. **禁止修改原生Prompt**：所有能力通过插件注入
6. **分层注入与动态加载**：插件按需加载，执行完成释放

## 调度层（plugin_runtime.py）

### 核心职责
- 插件注册与发现
- 任务路由分发
- 链式触发配置
- 三级异常降级保护
- 插件生命周期管理

### 三级降级保护
1. 捕获异常，记录故障日志写入系统健康快照
2. 尝试调用该插件的备用轻量版本（如果存在）
3. 备用版本失效，返回可控业务提示，不直接崩溃整个调度链路

## 插件契约标准

每个插件必须实现：
1. **统一接口**：handle_query(query, context) → result
2. **独立存储**：storage/目录下独立数据库
3. **元数据声明**：名称、版本、触发词、依赖、domain
4. **错误处理**：异常捕获，不向上传播崩溃
5. **快照支持**：可导出静态状态用于记忆匣

## 插件生成逻辑

### 初始逻辑（已废弃）
```
plugin_id = f"plugin_{en_name}_{时间戳后4位}"
```
问题：每次生成都创建新目录，造成大量重复垃圾插件（V4发现103个噪声插件）

### 当前逻辑
```
plugin_id = f"plugin_{en_name}"  # 固定命名
```
- 同名插件自动备份到`archive/plugin_backups/`后覆盖
- 从根源消除重复插件产生
- 同时保留回滚能力

### 输入验证
- 新增_get_supported_domains()方法
- 当domain为"通用"且名称为"未命名系统"时，返回needs_clarification提示
- 防止产生无意义插件

## 链式触发配置

```
用户输入
  ↓
UMA需求评估 ──不通过──→ 返回澄清需求
  ↓ 通过
蓝图生成器
  ↓
系统验证器（8维评分）
  ↓ 通过
孵化规划插件（里程碑+验收标准）
  ↓
系统矩阵登记（自动打范式标签）
  ↓
输出完整交付包
```

## 沙箱环境适配

### 数据分层
- **永久层**：插件定义、契约、架构规则 → 可通过记忆匣迁移
- **临时层**：运行时实例、缓存、计数器 → 沙箱回收后重置

### 快照机制
- 每轮自优化结束自动生成标准化文本快照
- 快照可直接追加至记忆匣
- 新会话载入快照后可完整重建插件体系

## 测试体系

- 全量105项测试套件
- 每轮自优化后必跑
- S级质量标准
- 测试耗时：29秒（优化后）
